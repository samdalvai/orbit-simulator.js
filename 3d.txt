3D implementation steps:

Recommended implementation order

For your engine:

Step 1

Add:

z
perspective projection

No rotation yet.

Step 2

Add yaw only.

This already allows:

rotating around solar systems
cinematic views
proper depth perception

Step 3

Add pitch.

Now you can:

tilt above/below orbital planes
get true orbital visualization
Step 4

Add roll if desired.

Usually optional for space sims.

------ Sorting of objects by depth (to be done in step 1)

type RenderItem = {
    index: number;
    depth: number;
    x: number;
    y: number;
    scale: number;
};

const renderItems: RenderItem[] = [];

for (let i = 0; i < bodyCount; i++) {
    const projected = camera.project(
        positionX[i],
        positionY[i],
        positionZ[i],
    );

    if (projected === null) {
        continue;
    }

    renderItems.push({
        index: i,
        depth: projected.depth,
        x: projected.x,
        y: projected.y,
        scale: projected.scale,
    });
}

renderItems.sort((a, b) => b.depth - a.depth);

Do NOT sort by raw world z.

Even in Step 1, use:

projected.depth

because later, when you add camera rotation, the code remains correct automatically
